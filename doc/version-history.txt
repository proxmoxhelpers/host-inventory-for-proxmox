0.9.2
-----
- Fixed jq 1.6 compatibility in build_report_model.sh by replacing reserved binder names used by the descriptive report model.
- Added a reporting-suite source guard for known jq 1.6 reserved binders so newer local jq versions cannot mask this regression class.
- No collector evidence, collector schema, host-map schema, evaluator policy, replay ladder, or passive timing semantics changed.

v0.9.1

- Added reports-only `run_complete.sh --from-run DIR` and optional `--skip-tests` while keeping fresh collection as the default.
- Added passive per-collector `collector-timings.tsv` and run-phase `run-timings.tsv` to run_all.sh; no additional benchmark or hardware probe is started.
- Added workflow-timings.tsv plus performance.txt, performance.json and self-contained interactive performance.html.
- Reused one host-map across the complete report-generation workflow instead of repeatedly harmonizing the same run.
- Added run_complete_test.sh and strengthened run_all_test.sh timing-artifact coverage.
- Collector schema remains 0.5.0; host-map schema remains 0.8.9; report/evaluation schemas remain 0.1.0.

v0.9.0

- Added latency/stutter/jitter/smoothness-only descriptive desktop reports at the same three densities.
- Added self-contained interactive HTML for all-views replay, every descriptive report mode, and desktop evaluation.
- Added Layer 3 desktop evaluator schema 0.1.0 with PASS/WARN/FAIL/UNKNOWN, severity, confidence, evidence, rationale and recommendation.

- Added reporting_test.sh with descriptive/evaluative separation, no-live-probe boundary and all HTML modes.
